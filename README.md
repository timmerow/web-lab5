# Лабораторная работа №5

## Локальный запуск

1. Запустите MySQL в XAMPP. Создайте базу `lab5_data` в phpMyAdmin и один раз импортируйте в неё `terms.sql`. Если у пользователя MySQL задан пароль, укажите свои параметры в `db.php`.
2. Запустите `Запустить сайт.cmd` и откройте [http://localhost:8005/](http://localhost:8005/).

`db.php` подключается к MySQL. `index.php` читает термины из базы, показывает таблицу, иллюстрации и форму. `add.php` получает данные формы через POST, сохраняет термин и показывает кнопку возврата.

Для нового термина укажите прямую ссылку на изображение, доступное по HTTP или HTTPS.

На этом компьютере база уже импортирована в контейнер MySQL `ovt-lab5-mysql`. Если он остановлен, запустите его командой `docker start ovt-lab5-mysql` и откройте `Запустить сайт.cmd`.
